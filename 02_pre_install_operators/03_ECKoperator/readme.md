# Elastic Stack Operator

Este repositorio contiene recursos y configuraciones relacionados con el operador de Elastic Stack.

## Contenido

- **Configuraciones**: Archivos de configuración para desplegar y gestionar Elastic Stack.
     CRD : conteine los objetos de tipo custom resoruce definition
     deployoperator_rbacrules: despliega el operador de ECK

## Requisitos

- Kubernetes 1.20 o superior.
- Acceso a un clúster de Kubernetes configurado.
